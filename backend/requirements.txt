# Phase 5 face recognition + liveness.
#
# insightface supplies the real ArcFace pipeline: SCRFD face detection, the
# documented five-point facial landmarks, and the ArcFace w600k_r50 recognition
# model (512-dimensional embeddings).
#
# Model weights are NOT on PyPI and are deliberately NOT downloaded at runtime.
# app/services/face_engine.py fails closed with HTTP 503 if the weights are
# absent, so they must be provisioned before the service starts. Provision
# buffalo_l (det_10g.onnx + w600k_r50.onnx) into backend/face_models, verified
# against the SHA-256 digests in docs/PHASE5_EVALUATION.md. See that document
# for the exact placement and integrity procedure.
#
# Pinning notes:
#   * opencv-python is pinned to 4.x. insightface 2.1 predates OpenCV 5 and
#     the 5.x release changed core signatures; 4.10.0.84 is the combination
#     the engine is exercised against.
#   * onnxruntime is the CPU inference backend.
#   * If the ArcFace weights cannot be loaded the face endpoints fail closed
#     (HTTP 503); they never fall back to a permissive answer.
